# TreeHub backend

A Cloudflare Worker (Go compiled with TinyGo to Wasm) and a D1 database that store, per
GitHub user, the TreeHub extension's repository **bookmarks** and pull request **review
queue** (with a per-PR "last seen" time). Pull request statuses are computed by the
extension; the server never stores GitHub tokens.

| Layer | Tech |
| --- | --- |
| API | Go `net/http` (`internal/api`) via [syumai/workers](https://github.com/syumai/workers), built with **TinyGo** |
| Database | Cloudflare D1 through `database/sql`; queries generated by **sqlc** (`internal/db/query.sql`) |
| Contract | **protobuf** `proto/treehub/v1/api.proto` → Go (`gen/go`) and TypeScript (`../app/src/gen`) via `buf generate` |
| Login | GitHub OAuth App (scope `repo`) through `chrome.identity.launchWebAuthFlow` |
| Session | JWT (HS256, 30 days) sent as `Authorization: Bearer <jwt>`; "sign out everywhere" bumps `users.token_version` |

The wire format is `encoding/json` over the protoc-gen-go structs (proto field names;
protojson does not work under TinyGo). The extension parses responses with protoc-gen-es
`fromJson`. Every response allows any origin (CORS `*`): auth is a bearer token, never a cookie.

## API

| Method | Path | Result |
| --- | --- | --- |
| GET | `/`, `/api/health` | `{"ok":true,"service":"treehub"}` |
| GET | `/auth/github/start?ext=<id>&nonce=<n>` | 302 to GitHub |
| GET | `/auth/github/callback` | 302 to `https://<ext>.chromiumapp.org/github#session=…&github_token=…&login=…&nonce=…` (or `#error=…&nonce=…`) |
| GET | `/auth/dev-login?ext=&nonce=&login=` | like the callback without `github_token`; only with `DEV_AUTH=true` |
| GET | `/api/me` | `MeResponse` |
| DELETE | `/api/me` | deletes the account with its bookmarks and queue (cascade) → `OkResponse`; its sessions stop working, a later sign-in starts an empty account |
| POST | `/api/logout-all` | revokes all sessions → `OkResponse` |
| GET / PUT / DELETE | `/api/bookmarks`, `/api/bookmarks/{owner}/{name}` | list (newest first) / add (idempotent) / remove |
| GET / PUT / DELETE | `/api/queue`, `/api/queue/{owner}/{name}/{number}` | list / add (body `PutQueueItemRequest`, optional title) / remove |
| POST | `/api/queue/{owner}/{name}/{number}/seen` | sets `last_seen_at` → `QueueItem` (404 if not queued) |

Errors are `ErrorResponse` (`login_required`, `invalid_repo`, `invalid_number`, `invalid_body`,
`not_found`, `method_not_allowed`, `limit_reached`, `internal`, …). Limits: 1000 bookmarks and
500 queued pull requests per user.

## Local development

Needs Node 20+, Go 1.26, TinyGo 0.42, and for code generation `buf`, `sqlc` and
`protoc-gen-go` (`go install google.golang.org/protobuf/cmd/protoc-gen-go@latest`).

```bash
npm install
cp .dev.vars.example .dev.vars      # put a random SESSION_SECRET in it (openssl rand -hex 32)
npm run db:migrate:local
make dev                            # builds the Wasm, then wrangler dev on http://localhost:8787
node scripts/smoke.mjs http://localhost:8787   # end-to-end check (needs DEV_AUTH=true)
```

`make test` runs the Go tests (handlers and SQL against an in-memory SQLite with the real
migrations). After editing the `.proto` or `query.sql`, run `make gen`. `wrangler dev` runs
`make worker` on start; restart it after Go changes.

## Deploying

1. `npx wrangler login`, then create the database and put its id into `wrangler.jsonc`
   (`database_id`):
   ```bash
   npx wrangler d1 create treehub
   npm run db:migrate:remote
   ```
2. Create a GitHub OAuth App (GitHub → Settings → Developer settings → OAuth Apps → New):
   - Homepage URL: `https://github.com/peterxcli/treehub`
   - Authorization callback URL: `https://treehub-api.<your-subdomain>.workers.dev/auth/github/callback`

   Put its Client ID into `wrangler.jsonc` `vars.GITHUB_CLIENT_ID` and generate a client secret.
   (An OAuth App has one callback URL; use a second app with
   `http://localhost:8787/auth/github/callback` to try the real login locally.)
3. `ALLOWED_EXTENSION_IDS` in `wrangler.jsonc` lists the extension IDs that may receive a
   session (the Chrome Web Store ID; add an unpacked build's ID while developing).
4. Deploy, then add the secrets (the Worker answers 500 until `SESSION_SECRET` is set):
   ```bash
   make deploy
   npx wrangler secret put SESSION_SECRET        # at least 32 random characters
   npx wrangler secret put GITHUB_CLIENT_SECRET
   curl https://treehub-api.<your-subdomain>.workers.dev/api/health
   ```

Never set `DEV_AUTH` in production. The Wasm bundle is about 0.75 MB gzipped (free-plan limit 3 MB).
